# 💻 Portfólio de Programação em C - 1º Período (UFCAT)

Bem-vindo ao meu repositório de introdução à programação! Este projeto contém o **Código Mestre**, um programa unificado em linguagem C que consolida todas as listas de exercícios e questões de prova desenvolvidas durante o meu primeiro período na Universidade Federal de Catalão (UFCAT).

## 🎯 Sobre o Projeto

O objetivo deste "Código Mestre" é demonstrar minha evolução na lógica de programação. Através de um **Menu Principal** interativo, é possível navegar por 9 listas de exercícios diferentes, que vão desde operações matemáticas básicas até a manipulação de ponteiros e matrizes.

## 📚 Tópicos Abordados

O programa está estruturado nas seguintes seções (Listas):

*   **Lista 1:** Operações Matemáticas Básicas (Cálculo de médias, conversão de tempo, áreas e volumes).
*   **Lista 2:** Condicionais (`if` / `else` / `else if`) (Validações de notas, IMC, par/ímpar, triângulos).
*   **Lista 3:** Menus de Opções (`switch` / `case`) (Sistemas de cálculo de salário, crédito e senhas).
*   **Lista 4:** Laços de Repetição I (`for`, `while`, `do-while`) (Fibonacci, números primos, tabuadas).
*   **Lista 5:** Laços de Repetição II e **Prova 1** (Tratamento de dígitos, crescimento populacional).
*   **Lista 6:** Vetores e Strings (Buscas, ordenação (Bubble Sort), palíndromos, manipulação de caracteres).
*   **Lista 7:** Matrizes e **Prova Substitutiva** (Matriz transposta, multiplicação de matrizes, matriz identidade, sub-vetores).
*   **Lista 8:** Modularização (Funções e Procedimentos).
*   **Lista 9:** Ponteiros e **Prova 2** (Passagem por referência, aritmética de ponteiros, alteração de endereços de memória).

## 🚀 Como Compilar e Executar

Como o código utiliza a biblioteca `<math.h>`, é necessário incluir a flag `-lm` durante a compilação no terminal (no Linux/macOS).

### Pré-requisitos
*   Um compilador C instalado (como o GCC).
